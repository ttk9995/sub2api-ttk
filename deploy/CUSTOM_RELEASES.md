# 自定义版本更新

自定义功能维护在 `ttk9995/sub2api-ttk` 的 `main` 分支，功能分支经 PR 检查、合并后发布。官方完整程序包含前端，直接安装官方发布会覆盖用户 API 密钥测试、后台模型测试、鹈鹕 SVG 预览和分组模型倍率等自定义功能。

版本使用 `v<上游版本>-ttk.<修订号>`，例如 `v0.2.17-ttk.2`。保留上游版本号用于核对官方修复，同一上游版本的修订号用于识别自定义更新。推送标签触发 `.github/workflows/release.yml`，从同一提交构建前端、各平台程序和镜像；正式 GitHub Release 需要包含目标平台压缩包和 `checksums.txt`。

后台在线更新只读取本仓库。安装自定义版本后，更新和下载式回退均排除没有 `-ttk.<修订号>` 的历史官方发布，旧更新来源的缓存也不会继续使用。同步上游时须保留自定义功能，并验证管理员账号测试和用户密钥测试入口。

Docker 镜像发布到 `ghcr.io/ttk9995/sub2api`，部署时固定已验证的版本。应用内更新只修改容器可写层中的程序，不会改变镜像标签；重建容器应使用对应的新版本镜像，避免恢复为旧程序。核对版本时同时检查容器镜像及实际运行程序版本。

`v0.2.17-ttk.2` 恢复鹈鹕、知识和计数测试，加入分组模型候选选择，并修正自定义更新来源。

`v0.2.17-ttk.3` 在用户和管理员的费用明细中显示实际扣费倍率；1.00x 的实际倍率和基础分组倍率会隐藏。本次不涉及数据库结构变更。

`v0.2.17-ttk.4` 将 GPT-6.1 Sol 的 API Key 接入账号默认长上下文计费阈值同步为 500K（含缓存、含边界），并兼容旧远程价表。OAuth/SetupToken 保留订阅豁免，其他模型和渠道自定义定价保持原有规则。本次不涉及数据库结构变更。

`v0.2.17-ttk.5` 同步官方上游至 `7da09cab4`，包含流式断开计费、调度快照缓存、Gemini 生图权限、Vertex 配额和依赖安全修复。GPT-6.1 Sol 的 API Key 默认长上下文阈值恢复为 272000 token；OpenAI/聚合分组新增自定义计费阈值与独立开关，例如启用并填写 500000 后，严格超过该值才进入长上下文档。原有计费倍率、订阅账号豁免及渠道显式区间继续生效。

该版本启动时通过现有迁移链执行官方 `246_enable_gemini_image_generation_groups.sql` 和自定义 `247_group_gpt61_sol_long_context.sql`。后者仅为分组新增两个配置字段，默认关闭自定义阈值。部署前备份数据库及运行镜像；程序回退可保留新增字段，官方迁移对 Gemini 生图开关的调整应根据备份单独核对。
